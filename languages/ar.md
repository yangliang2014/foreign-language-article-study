# 阿拉伯语（ar）精读 playbook

填 draft 前读本文件。通用流程见 [../SKILL.md](../SKILL.md)；本文件只说阿语特有的坑。

## 适用语体

- skill 只支持**现代标准阿拉伯语（MSA / الفصحى）**的新闻书面语。埃及、黎凡特、海湾等口语方言与 MSA 词汇句法差异巨大，不在目标内。
- 注释语言仍为中文；所有中文注释块自动保持 LTR，只有阿语原文行 RTL。

## 信源与取文

- 首选：**Al Jazeera Arabic**（aljazeera.net）、**BBC Arabic**、Al Arabiya、RT Arabic、Sky News Arabia、Al-Ahram；均有较干净 `<article>`，直接 `prep --lang ar "<URL>"`。
- 学习信源：阿语学习站点上改写的 MSA 短新闻（约 200~400 词）优先；正式通讯社稿句子偏长，适合 B2 以上。
- 脚本按阿拉伯文种探测（≥20 个阿拉伯字母即判 ar，忽略错标的 `<html lang=en>`）；成品 HTML 自动打 `dir="rtl"`，原文句右对齐、竖线与序号镜像。
- 部分阿语站点把动符（حَرَكَات）写进正文：动符是真字符，ph/hl 必须**连同动符逐字照抄**；多数新闻无动符，无动符时不要自己补。
- 数字可能是东阿拉伯数字（٠١٢٣٤٥٦٧٨٩），照抄。

## 断句

- 断句器是 `rtl`：句末符为西方句号 `.`、叹号 `!`、**阿语问号 `؟`（U+061F，方向朝右）**，后跟空格即断，不查大小写、无缩写表。
- **阿语逗号 `،`（U+060C）、分号 `؛`（U+061B）不断句**，再长的复句也不断，由你在 draft 里按通用拆句规则手动拆。
- 数字小数分隔符是阿语小数点 `٫`（U+066B），与句末 `.` 不同，不会误断。
- 句号后紧跟闭引号 `» ” "` 已处理（含空格再跟闭引号的法式排版）。
- MSA 长句常含多个分句，骨架倾向保守（整段一句）——这是预期行为，精读价值正在拆句：在 draft 同块内拆多组，每组给完整 zh/gr。
- 零宽连接符（ZWNJ/ZWJ）若被站点混入，对覆盖校验透明，无需手工处理。

## 填 draft（zh / gr / ph / hl）

四字段结构不变。`> en:` 装阿语原文（只读）。

### gr：用 `｛｝` 标阿语语法点

常用包：
`｛名词句 الجملة الاسمية｝`、`｛动词句 الجملة الفعلية｝`、`｛过去式 الماضي｝`、`｛现在式 المضارع｝`、`｛命令式 الأمر｝`、`｛被动 المبني للمجهول｝`、
`｛三/双/复数 单数-双数-جمع｝`、`｛正偏组合 الإضافة（属格修饰）｝`、`｛指/泛指 冠词ال/鼻音符｝`、
`｛四个格 主/宾/属格｝`、`｛宾语 المفعول به｝`、`｛状态状语 الحال｝`、`｛区分 التمييز｝`、
`｛介词 من/إلى/عن/في/على/لـ｝`、`｛否定 لم/لن/لا/ما｝`、`｛使名词句动词化 كان وأخواتها｝`、`｛إنّ وأخواتها 强调｝`、
`｛将来 سـ/سوف｝`、`｛完成 قد｝`、`｛条件句 إن/إذا｝`、`｛关系代词 الذي/التي｝`、`｛指示代词 هذا/تلك｝`、
`｛数词结构 العدد｝`、`｛动名词 المصدر（masdar）｝`、`｛主动/被动名词 اسم الفاعل/المفعول｝`、`｛词根性 أنّ/أن｝`。

### ph：写连写后的实际形态，不收三辅音词根

阿语词大量靠前后附缀连写（介词、冠词、代词后缀全部粘在词上），ph 写**源文中整词的实际连写形态**。

- 对：`بالمدرسة`（在学校＝ب+ال+مدرسة）、`قالوا`（他们说了＝قال+وا）、`لن يذهبوا`、`في المدينة`、`من أجل`
- 错：`ذهبَ`（词典形且带源文没有的尾符）、`ذ-ه-ب`（词根）、`مدرسةٌ`（自补鼻音符）、`الـ N`（占位）
- 介词与名词常连成一个词（`للطلاب`＝ل+ال+طلاب），整词收；空格分隔的（`في البيت`）整段连续收。
- hl 逐字方向不用管：浏览器会在 RTL 行内正确渲染 `<mark>`，你只需保证字符序列一致。

### zh

正偏组合（IDĀFA：مدرسةُ الأولاد 字面"孩子们的学校"）先译中心名词再补"的"字修饰；动词句以动词开头（VSO），中文重排为 SVO；双数/复数在中文用数量词体现（两个、许多）。

## 朗读与字体

- 朗读 `ar-SA`；字体走 macOS 阿语栈（Geeza Pro / Noto Naskh Arabic / Damascus）。
- **核对截图只看原生分辨率分片**：1300px 长截图缩小后阿语连字可能断裂/错位，属缩放伪影；拿不准用元素级原尺寸截图核对。
- 阿语从右向左书写，句中嵌入的拉丁词/数字由浏览器双向算法处理，无需手工调序。

## 非目标

- 方言（埃及/黎凡特/海湾等）不支持。
- 不自动补动符、不还原阿拉伯数字与西方数字。
- 古兰经学/古旧句法不处理。
