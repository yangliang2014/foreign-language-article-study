# 日语（ja）精读 playbook

填 draft 前读本文件。通用流程见 [../SKILL.md](../SKILL.md)；本文件只说日语与英语流程的差异。

## 信源与取文

- **NHK NEWS WEB EASY** 是首选信源（简易新闻、词汇句型规范）。官网 2026 年改版后 `www3.nhk.or.jp/news/easy/` 是 Next.js + JWT，curl/headless 都取不到文章列表，不必硬刚。
- 稳定信源是学习镜像 **nhkeasier.com**：`https://nhkeasier.com/story/<id>/`，curl 直连即可。镜像页 `<html lang=en>` 是错标的，脚本按假名文种探测，不影响识别。
- 镜像正文是带注音的 `<ruby>電車<rt>でんしゃ</rt></ruby>`，**脚本会自动剥除 `<rt>` 只留汉字基底**（skeleton 与 inject 同源，无需手工清洗、不要手写替换 JSON）。
- 镜像 h1 是站名「NHK Easier イーシア」，不是文章标题；文章真实标题取 `og:title`。对这种站不能直接 prep，参照试读成品的做法：用脚本 `render(..., lang="ja")` 重建干净 HTML（或手工构造同构 HTML，`<html lang="ja">`、`出典：` source），再 skeleton。
- 普通日语站（有干净 `<article>`、无注音）直接 `prep --lang ja "<URL>"`。

## 断句

- 句末符是 `。．！？!?`，后面可跟闭括号 `」』）)｝】｠〉》`；**不需要空格或大写**。`？！`、`！！！` 等连续句末符整体吞掉。
- **读点 `、` 不是句末**，再长的并列也不断；但 `〜ましたが、〜ます` 这种转折复句是否拆成两句由你判断（建议拆，方便逐句分析）。
- 引号内即使有 `。`（罕见于新闻）也按标点处理，骨架按字符断；断错了按 SKILL.md 的拆句/合句规则在 draft 里修。
- 骨架断句结果以「自动断句 N 条」核对；EASY 新闻一个 `<p>` 常含多句，确认 N 符合预期再填。

## 填 draft（zh / gr / ph / hl）

四字段结构不变。`> en:` 虽以 en 为名，装的是日语原文（只读）。

### gr：用 `｛｝` 标日语文法点（而非英语时态/从句）

常用包：`｛て形相继｝`、`｛动词简体作定语｝`、`｛イ形容词连用形く＋なる/する｝`、`｛他动词てある 结果状态｝`、`｛ている｝`、`｛が 接续助词（转折）｝`、`｛条件 と/ば/たら｝`、`｛名词＋にする（选择）｝`、`｛ことができる（可能）｝`、`｛ようにする（设法实现）｝`、`｛愿望助动词たい｝`、`｛间接引用｝`、`｛名词谓语句｝`、`｛主题对比 は｝`、`｛共同动作对象 と｝`、`｛动作场所 で｝`、`｛比较基准 より｝`、`｛数量＋ぐらい 约数｝`、`｛礼貌体ます/简体｝`、`｛受身｝`、`｛使役｝`、`｛授受 てあげる/てくれる/てもらう｝`、`｛ながら｝`、`｛の 同位概括｝`。

### ph：写句中实际形态，不要写辞书形

与英语同规则：**必须是句中逐字连续片段**，写实际活用后的形态，禁止辞书形与占位符。

- 对：`かいてあります`（辞书形 書く→てある）、`使うことができる`、`ようにしたい`、`見せて通ります`、`の7つです`、`今より`
- 错：`書く`、`書いてある`（句中是ます体）、`〜ようにする`、`と相談する`、`Vことができる`

小颗粒助词搭配也值得收（`今までは`、`にすると`、`と言っています`），但单个裸助词 `は/が/を` 不要收。

### zh

准确通顺即可，语序不必贴日文；长定语句先译核心名词再补修饰。EASY 新闻的数词+助词（`7つ`＝七个、`3倍ぐらい`＝大约 3 倍）要译准。

## 朗读与字体

- 朗读自动用 `ja-JP`，下拉只列日语语音；没有日语语音的设备会静默回退系统默认。
- 字体走 macOS 日语黑体栈（Hiragino Sans / Yu Gothic / Noto Sans JP / PingFang SC）。**核对截图只看原生分辨率分片**：1300px 分片在预览里被缩小后，黑体笔画可能看着像明朝体，属缩放伪影，不是 bug——拿不准就用 CDP 按元素 `getBoundingClientRect` 截原尺寸图确认。

## 非目标

- 送假名、汉字异写、敬语深入辨析超出精读块容量，点到为止。
- 竖排、ルビ保留显示暂不支持（注音一律剥除）。
