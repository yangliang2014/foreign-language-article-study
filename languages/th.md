# 泰语（th）精读 playbook

填 draft 前读本文件。通用流程见 [../SKILL.md](../SKILL.md)；本文件只说泰语特有的坑。

## 信源与取文

- 普通新闻：Thai PBS（thaipbsworld.com 有英文；泰文站 news.thaipbs.or.th）、BBC Thai、The Standard（thestandard.co）、มติชน/เดลินิวส์；直接 `prep --lang th "<URL>"`。
- 初学者优先选 Thai PBS 少年/生活栏目稿，句子短；政治稿常含括注英文名与职衔，拆句负担重。
- 泰语标点极少：**段落里基本没有句号**，靠空格分隔句子（空格同时兼当逗号/语气停顿），这是本语言最大的差异点（见断句）。
- 零宽空格（ZWSP, U+200B）常被网站塞进泰文做隐形换行提示，对覆盖校验与高亮透明（自动忽略），不用手工清。

## 断句

- 断句器是 `thai`：**按连续空白切一切**，骨架会把空格两侧各切成一条候选句。
- 泰文空格经常只是长句/并列的停顿，不等于句子边界——**骨架必然过度切分**。你的主要工作是在 draft 里**合句**：把多条 `> th:` 接成一行、zh/gr/ph/hl 合并为一组（规则同 SKILL.md 合句）。
- 判据：空格后若是新的主谓结构/新话题/句末礼貌词（ครับ/ค่ะ/นะ/ครับผม）收尾后另起，才是真句界；`และ`（和）、`แต่`（但是）、`หรือ`（还是）、`เพราะ`（因为）、`ซึ่ง`（关系）、`โดย`（通过）引导的延续，多为分句，应合并。
- 句末疑问句句尾是疑问词（ไหม/อะไร/ที่ไหน/ทำไม/อย่างไร/หรือไม่）而非问号；感叹/命令有时出现 `! ?`，出现就正常断。
- 段落数校验按 `<p>`，合句后同段各 `> th:` 拼接必须覆盖整段（去空白逐字）；泰文没有词间空格，拼接时不要加空格，除非源文该位置本来就有空格。
- 若整段只有一个长句未切（源文无空格），直接一组即可，不必为拆而拆——拆句服务于逐句讲解，过长再按主谓手工拆两组（切点必须落在源文空格处，否则覆盖校验对不上）。

## 填 draft（zh / gr / ph / hl）

四字段结构不变。`> en:` 装泰语原文（只读，命名是历史遗留）。

### gr：用 `｛｝` 标泰语语法点

常用包：
`｛句末礼貌词 ครับ/ค่ะ｝`、`｛判断句 เป็น/คือ/อยู่｝`、`｛话题标记 น่ะ/ล่ะ｝`、
`｛将来 จะ｝`、`｛进行 กำลัง｝`、`｛持续 อยู่｝`、`｛完成 แล้ว｝`、`｛经历 เคย｝`、`｛过去 ได้｝`、
`｛否定 ไม่/ไม่ได้/ไม่เคย｝`、`｛禁止 ห้าม｝`、`｛必须 ต้อง｝`、`｛应该 ควร｝`、`｛愿望 อยาก｝`、`｛能 สามารถ/ได้｝`、
`｛请求 ช่วย…หน่อย｝`、`｛ให้ 使役｝`、`｛ไป/มา 动作方向｝`、`｛连动结构｝`、
`｛定语在名词后 ที่/ซึ่ง｝`、`｛比较 กว่า｝`、`｛最高级 ที่สุด｝`、`｛等价 เท่า/เหมือน｝`、
`｛量词＋名词（ลูก/คน/อัน）｝`、`｛数词在名词后｝`、`｛并列 และ/กับ｝`、`｛转折 แต่｝`、`｛原因 เพราะ/เนื่องจาก｝`、
`｛零主语（省略代词）｝`。

### ph：收连续的"词块"，不要收单音节

泰语词不空格，很多语法意义是**多音节词块**（อาจจะ、ไม่ได้、ที่จะ、ต้องการจะ），ph 必须是源文中连续的字符序列。

- 对：`ไปโรงเรียน`（去上学）、`กำลังกินข้าว`（正在吃饭）、`มีความสุข`（幸福）、`ไม่สบาย`（不舒服）、`ที่จะไป`（要去……的）
- 错：`ไป`（裸单音节，义太泛）、`V แล้ว`、`N ของ`（占位）、句中实际是 `ทานข้าว` 却写 `กินข้าว`
- 句末礼貌词可作为搭配收：`ขอบคุณครับ`、`สวัสดีค่ะ`。
- 没有大小写概念，但**要与源文逐字一致**——泰文有大量组合字符（基字+上下元音+声调符），直接复制 `> en:` 行内的原串最保险，不要手敲。

### zh

泰语零主语普遍，中文补出主语；量词结构"หนังสือ 2 เล่ม"译"两本书"；定语在名词后（บ้านที่ใหญ่＝大的房子），中文提前。

## 朗读与字体

- 朗读 `th-TH`；字体走 macOS 泰文栈（Thonburi / Sukhumvit Set / Noto Sans Thai）。
- **核对截图只看原生分辨率分片**：缩小时声调符与上下元音可能与基字错位，属缩放伪影。
- TTS 对合句后的长句也能整句朗读；句子块内不另做词界切分。

## 非目标

- 不做泰文分词（匹配按字符串，不需要词界）。
- 不转写拉丁拼音（ph 只用泰文原串）。
- 王室用语、巴利梵借词的语体辨析点到为止。
